# 🌐 sanyi-hot

> jobhunt-copilot web-ui — AI 求职副驾网页工作台

## ✨ 功能

- 📋 **求职任务管理**：每日新岗位 + 投递记录
- 📊 **JD 评分**：智能分析岗位匹配度
- 🤖 **AI 简历定制**：基于 JD 自动调整简历
- 📅 **面试管理**：日程 + 复盘 + 题库

## 🚀 启动

```bash
cd /home/ubuntu/jobhunt-copilot-webui/web
python3 app.py  # 端口 8787
```

访问 http://localhost:8787
