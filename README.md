# 三医改革 · 热点观察

> 医疗 · 医保 · 医药 协同改革资讯聚合平台 —— 按热度排行，实时追踪全国医改动态。

一个零依赖的单文件静态网站，参考 [AI HOT](https://aihot.virxact.com) 的热点聚合模式，采用政务资讯风格设计。服务端每 15 分钟自动聚合一次"三医改革"相关新闻，计算热度指数并生成排行榜，国内访客访问稳定、速度快。

## 功能特性

- **热度排行榜**：TOP 10 热点资讯，前三名金/银/铜标识，热度指数综合发布时效、来源权威度与改革关键词权重计算。
- **三级数据兜底**：优先读取服务端定时生成的 `data.json`（对国内访客最稳）→ 浏览器端实时抓取 → 内置演示数据，网页永远有内容。
- **分类与检索**：医疗 / 医保 / 医药 / 综合 分类筛选，关键词搜索，按热度/时间排序。
- **实时快讯**：滚动播报最新热点，支持悬停暂停。
- **自动更新**：服务端 cron 每 15 分钟抓取一次；页面打开期间每 10 分钟自动刷新。
- **政务资讯风**：政务蓝 + 中国红配色，宋体标题 + 黑体正文，数据速览、关键词云、滚动快讯等动态元素。

## 工作原理

```
┌─────────────┐   每15分钟    ┌──────────────┐   读取        ┌──────────┐
│ Google News │ ───────────> │ update-news.py│ ──data.json─> │  访客浏览器 │
│ (rss2json)  │   服务器抓取   │  计算热度/分类 │               │  展示排行榜 │
└─────────────┘              └──────────────┘               └──────────┘
```

抓取由**服务器**完成（而非访客浏览器），因此国内访客无需访问 Google 也能看到实时数据。抓取失败时自动沿用最近数据或切换演示数据。

## 部署（腾讯云）

### 前置条件

- 一台腾讯云服务器（**推荐香港/海外地域**：无需 ICP 备案，且能正常访问 Google 新闻源；大陆地域无法抓取 Google，将长期显示演示数据）。
- 本地 Windows 电脑（用 PowerShell 上传文件）。

### 步骤

**1. 控制台放行端口**（最关键）：腾讯云控制台 → 服务器 → 防火墙/安全组 → 添加规则 `TCP / 80 / 0.0.0.0/0`。

**2. 上传部署包**（PowerShell，替换为你的公网 IP）：

```powershell
scp sanyi-hot.tar.gz root@你的服务器IP:/root/
```

**3. 登录并一键安装**：

```powershell
ssh root@你的服务器IP
```

```bash
cd /root && tar -xzf sanyi-hot.tar.gz && cd sanyi-hot && sudo bash install.sh
```

> 想用非 80 端口：`sudo bash install.sh 8080`（并在安全组放行 8080）。

**4. 访问**：浏览器打开 `http://你的公网IP/` 即可。

## 常见问题

**打不开网页？** 99% 是安全组没放行端口，回控制台确认 TCP 80 已放行。

**显示"演示数据"？** 服务器在大陆地域，无法访问 Google 新闻源。换香港/海外地域服务器即可。查看日志：`cat /var/log/sanyi-hot-update.log`

**手动触发一次更新**：

```bash
SANYI_SITE_DIR=/var/www/sanyi-hot python3 /opt/sanyi-hot/update-news.py
```

**绑定域名？** 香港/海外服务器可直接解析域名并改 Nginx 的 `server_name`，无需备案；大陆服务器需先完成 ICP 备案。

**修改抓取关键词？** 编辑 `/opt/sanyi-hot/update-news.py` 顶部的 `QUERIES` 列表，保存后手动跑一次脚本生效。
